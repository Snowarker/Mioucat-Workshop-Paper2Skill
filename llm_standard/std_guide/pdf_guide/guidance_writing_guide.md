# 指导文档撰写指南

## 概述

本文档详细说明如何撰写和维护 PDF 文档处理规则指南（Guidance），确保处理规则的一致性、完整性和可追溯性。通过本章节，您将了解如何创建和更新期刊处理规则，以及如何确保规则的持续进化。

## 核心原则

1. **持续进化原则**：随着处理文献数量的增加，不断更新和完善处理规则
2. **DOI 信息优先**：在处理过程中优先提取和记录 DOI 信息，确保文档可追溯性
3. **章节完整性**：在 guide 中不断罗列最新看到的文章章节标题和部分，确保无遗漏
4. **质量控制精神**：宁可多检查一些，不要有遗漏，确保处理的完整性和准确性
5. **案例集成**：每个期刊的处理方法文档本身就是处理案例，无需额外创建案例库

## 撰写要求

### 1. DOI 信息处理

- **提取优先级**：在处理过程中优先查找和确认 DOI 信息
- **信息记录**：将 DOI 信息作为文档的重要标识之一
- **方法优化**：随着处理文献增多，不断优化 DOI 信息的提取和验证方法
- **查找位置**：
  - 文档末尾的 **Additional Information** 或 **Supplementary Information** 部分
  - 文档开头的摘要部分
  - 文章的出版信息区域
- **验证方法**：
  - 确认找到的 DOI 格式正确（通常以 "10." 开头）
  - 验证 DOI 是否可访问
  - 确保使用 DOI 的完整后缀作为唯一标识符

### 2. 章节识别与检查

- **结构记录**：详细记录期刊特有的章节结构和标题格式
- **方法说明**：对每个章节的识别方法和处理规则进行详细说明
- **完整性检查**：建立章节完整性检查机制，确保无遗漏
- **检查流程**：
  1. **数量检查**：统计章节文件数量与入口文档引用数量
  2. **顺序检查**：对比原始 MD 文档与入口文档的章节顺序
  3. **完整性验证**：检查所有章节是否都在入口文档中被引用

### 3. 格式处理说明

- **特殊格式**：明确数学公式、特殊符号等格式的处理方法
- **图片处理**：说明图片处理和引用的标准流程
- **解决方案**：提供常见格式问题的解决方案
- **格式一致性**：确保处理后的文档格式一致，便于后续处理

### 4. 质量控制流程

- **多层次检查**：建立多层次的质量检查机制
- **检查项说明**：详细说明检查项和验证方法
- **问题解决**：提供质量问题的识别和解决流程
- **重复分析**：允许重复的质量控制检查，确保无遗漏

### 5. 更新机制

- **定期更新**：定期检查和更新处理规则
- **更新记录**：记录规则更新的原因和效果
- **一致性保证**：确保规则的一致性和可追溯性
- **版本控制**：保持处理规则的版本历史，便于追踪变化

## 期刊处理规则文档结构

### 基本结构

1. **基本信息**：期刊名称、出版社、ISSN 等
2. **结构特点**：期刊特有的章节结构和格式
3. **处理流程**：针对该期刊的具体处理步骤
4. **章节识别**：章节标题的识别方法和规则
5. **格式处理**：特殊格式的处理方法
6. **质量控制**：针对该期刊的质量检查要点
7. **更新记录**：规则的更新历史

### 命名规范

- **文件名格式**：`{六位数编号}_{期刊名称}.md`
- **编号规则**：从 000001 开始递增，确保唯一性
- **目录位置**：存储在 `llm_standard/std_guide/pdf_guide/` 目录中

## 索引管理

### 规则索引

- **索引文档**：`llm_standard/std_guide/pdf_guide/index.md`
- **索引内容**：包含所有期刊处理规则的目录，按编号顺序排列
- **更新要求**：添加新规则时必须更新索引文档

### 交叉引用

- **内部引用**：在处理规则文档中引用相关的标准和规范
- **外部引用**：引用主技能文档中的通用处理流程
- **版本控制**：确保引用的文档版本一致

## 最佳实践

1. **模板使用**：使用标准化的模板创建新的处理规则文档
2. **案例积累**：通过处理实际论文积累案例和经验
3. **持续优化**：根据处理结果不断优化处理规则
4. **团队协作**：建立团队协作机制，共享处理经验
5. **文档管理**：建立完善的文档管理体系，便于规则的维护和更新

## 常见问题及解决方案

| 问题类型 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 规则过时 | 期刊格式变化 | 定期检查和更新处理规则 |
| 章节识别错误 | 标题格式不一致 | 扩展标题识别规则，考虑多种格式 |
| 格式处理问题 | 特殊格式处理不当 | 优化格式处理规则，确保正确显示 |
| 信息遗漏 | 检查不充分 | 建立更全面的检查机制，宁可多检查 |
| 规则冲突 | 不同规则之间存在冲突 | 统一规则标准，消除冲突 |

## 总结

Guidance 撰写规范是确保 PDF 文档处理规则质量的重要保障。通过遵循本章节的指南，您可以创建和维护高质量的处理规则，确保文档处理的一致性和准确性。

随着期刊格式的不断变化和处理经验的积累，处理规则也需要持续进化和完善。通过建立有效的更新机制和质量控制流程，您可以确保处理规则始终保持最新状态，为 Paper2Skill 工具的使用提供可靠的支持。
