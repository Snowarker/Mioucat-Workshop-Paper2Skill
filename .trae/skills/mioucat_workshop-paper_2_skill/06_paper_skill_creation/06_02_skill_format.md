# Paper Skill 文档格式

## 概述

本文档详细说明 Paper Skill 文档的格式和内容要求，包括技能文档的命名规范、结构设计和内容组织，确保创建的技能文档符合项目的标准和要求。

## 重要强调

### 技能命名规范

**技能命名是 Paper Skill 创建的核心环节，必须严格遵循以下规范：**

1. **语言要求**：对于英文文献，技能名称必须使用英文
2. **格式规范**：按照 [核心技术术语]-[期刊全称]-[发表年份] 的格式组合
3. **大小写**：技能名称使用 PascalCase 格式，目录名称使用全小写
4. **文档内容**：技能文档内部的主要语言应使用中文，以面向中文用户

**重要提醒**：在为英文文献创建技能名称时，不得使用中文或其他语言的词汇，必须确保所有术语和期刊名称都使用英文表达。

## 命名规范

### 技能文档命名

Paper Skill 的命名应遵循以下格式：

```
[核心技术术语]-[期刊全称]-[发表年份]
```

#### 规则说明

1. **核心技术术语**：
   - 选择文章中最具代表性、独特的专业术语或技术缩写
   - 优先考虑文章标题、摘要或引言中反复强调的技术创新
   - 应能准确反映文章的核心内容和技术特点
   - 多个词组成的术语使用下划线 (_) 连接

2. **期刊全称**：
   - 使用期刊的完整名称
   - 期刊名称中的空格使用连字符 (-) 替换
   - 保持期刊名称的大小写一致性

3. **发表年份**：
   - 使用文章发表的年份（四位数字）
   - 放置在命名的最后部分

4. **语言要求**：
   - **技能名称**：对于英文文献，技能名称必须使用英文
   - **术语表达**：确保所有术语和期刊名称都使用英文表达
   - **文档内容**：技能文档内部的主要语言应使用中文，以面向中文用户
   - **避免混用**：避免在技能名称中使用中文或其他语言的词汇

5. **大小写规范**：
   - 技能名称：使用 PascalCase 格式，单词首字母大写
   - 目录名称：使用全小写字母，单词间使用下划线或连字符连接

### 目录命名

- **目录名称**：使用全小写字母，遵循与技能文档相同的命名格式
- **示例**：`lip_srm-nature_biotechnology-2014`
- **注意**：目录名称中不应包含大写字母，以保持与项目其他部分的一致性

## 技能文档结构

### 结构设计原则

Paper Skill 的结构设计应遵循 [逻辑层级结构](../02_skill_creation/02_02_logical_structure.md) 中的原则：

- **从宏观到微观**：先概述技能整体情况，再详细展开具体内容
- **层次分明**：使用清晰的标题层级，确保文档结构清晰
- **逻辑连贯**：各部分之间保持逻辑连贯性，确保内容流畅
- **重点突出**：将核心技术和关键信息放在显著位置

### SKILL.md 格式

```markdown
---
name: [技能名称]
description: [技能描述]
---

# [技能名称]

## 技能概述

[技能概述内容]

## 核心技术

[核心技术内容]

## 实验设计与数据分析

[实验设计与数据分析内容]

## 应用与拓展

[应用与拓展内容]

## 方法学细节

[方法学细节内容]

## 结果与发现

[结果与发现内容]

## 技术局限性

[技术局限性内容]

## 未来发展方向

[未来发展方向内容]

## 原始文献信息

[原始文献信息内容]

## 技能应用指南

[技能应用指南内容]
```

### 内容要求

1. **技能概述**：简要介绍技能的背景、目的和核心内容
2. **核心技术**：详细描述技术的工作原理、流程和创新点
3. **实验设计与数据分析**：说明实验设计思路、数据收集和分析方法
4. **应用与拓展**：介绍技术的应用场景和可能的拓展方向
5. **方法学细节**：提供详细的实验步骤、材料和设备要求
6. **结果与发现**：总结实验结果和关键发现
7. **技术局限性**：客观分析技术的局限性和不足
8. **未来发展方向**：展望技术的未来发展和改进空间
9. **原始文献信息**：提供完整的文献引用信息
10. **技能应用指南**：提供技能的适用场景、实施步骤和注意事项

## 索引文件格式

### 格式规范

```markdown
| 技能文档 | 源文档 | 来源路径 | 对应 LLM 文档 |
|---------|--------|----------|---------------|
| [技能名称] | [源文档标题] | [技能文档路径] | [LLM 文档路径] |
```

### 示例

```markdown
| 技能文档 | 源文档 | 来源路径 | 对应 LLM 文档 |
|---------|--------|----------|---------------|
| LiP_SRM-Nature_Biotechnology-2014 | Global analysis of protein structural changes in complex proteomes | [SKILL.md](lip_mass/lip_srm-nature_biotechnology-2014/SKILL.md) | [nbt.2999.md](../../llm_processed/Springer_Nature/Nature_Biotechnology/nbt.2999/nbt.2999.md) |
```

## 最佳实践

1. **准确性**：确保技能文档内容准确反映原始文章的核心内容
2. **完整性**：包含技能的各个方面，从技术原理到应用指南
3. **一致性**：保持命名规范和目录结构的一致性
4. **可读性**：使用清晰的结构和格式，提高文档的可读性
5. **可追溯性**：确保技能文档能够追溯到原始源文档
6. **同步更新**：每次新建或修改技能文档时，同步更新相应分类目录下的索引文件
7. **交叉引用**：在不同分类目录中创建的技能文档应在所有相关索引文件中更新
8. **路径一致性**：确保索引文件中的路径正确指向技能文档和对应 LLM 文档
