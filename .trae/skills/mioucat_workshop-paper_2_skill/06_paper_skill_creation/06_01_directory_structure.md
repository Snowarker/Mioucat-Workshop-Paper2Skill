# Paper Skill 目录结构

## 概述

本文档详细说明 Paper Skill 的目录结构和组织方式，包括分类方法、目录层次和使用指南，确保技能文档的组织符合项目的标准和要求。

## 分类方式

Paper Skill 采用三种主要分类方式：

1. **按期刊分类 (by_journal)**：按照文章发表的期刊进行分类
2. **按方法分类 (by_method)**：按照文章中使用的实验方法或技术进行分类
3. **按主题分类 (by_topic)**：按照文章的研究主题进行分类

## 目录结构

### 基本结构

```
paper_skills/
├── README.md                  # 本入口文档
├── by_journal/                # 按期刊分类
│   ├── index.md               # 期刊分类索引
│   ├── journal1/              # 具体期刊
│   │   └── skill_documents/   # 该期刊的技能文档
│   └── journal2/
├── by_method/                 # 按方法分类
│   ├── index.md               # 方法分类索引
│   ├── method1/               # 具体方法
│   │   └── skill_documents/   # 该方法的技能文档
│   └── method2/
└── by_topic/                  # 按主题分类
    ├── index.md               # 主题分类索引
    ├── topic1/                # 具体主题
    │   └── skill_documents/   # 该主题的技能文档
    └── topic2/
```

### 详细说明

1. **主题分类**：根据文章的研究主题，将技能文档放置在相应的主题目录下
2. **技能目录**：每个技能对应一个独立的目录，目录名称使用全小写字母
3. **SKILL.md**：每个技能目录中必须包含一个 SKILL.md 文件，作为技能的入口文档
4. **索引文件**：每个分类目录下应包含一个 index.md 文件，记录该分类下的所有技能文档

## 使用指南

### 1. 文档添加流程

1. **LLM 处理**：首先在 `llm_processed` 目录中完成文档的处理
2. **技能提取**：从处理后的文档中提取技能知识
3. **分类归档**：根据文章的期刊、使用的方法和研究主题，将提取的技能知识分别归档到对应的分类目录中
4. **更新索引**：更新相应分类目录下的 `index.md` 文件，添加新文档的信息

### 2. 索引文件结构

每个分类目录下的 `index.md` 文件应包含以下内容：

- **分类说明**：该分类的定义和目的
- **子分类列表**：该分类下的所有子分类
- **文档映射**：每个子分类下的技能文档及其对应的源文档

### 3. 技能文档格式

技能文档应包含以下内容：

- **文档来源**：原始文章的标题、作者、期刊等信息
- **技能摘要**：提取的核心技能信息
- **详细说明**：技能的具体内容和应用方法
- **相关资源**：相关的代码、数据或其他资源
- **引用信息**：引用的原始文章信息

## 管理原则

1. **多维度分类**：同一篇文章的技能知识可以同时出现在多个分类中
2. **索引更新**：每次添加新文档后，及时更新相应的索引文档
3. **一致性**：保持技能文档的格式和结构一致
4. **可扩展性**：随着文档数量的增加，及时调整分类结构

## 后续步骤

1. **创建初始分类**：根据现有文档创建初始的分类目录
2. **提取技能知识**：从处理后的文档中提取技能知识
3. **建立映射关系**：在索引文件中建立技能文档与源文档的映射关系
4. **定期维护**：定期检查和更新分类结构和索引文档

通过这种结构化的管理方式，您可以更有效地组织和检索从文献中提取的技能知识，为后续的研究和应用提供有价值的参考。
