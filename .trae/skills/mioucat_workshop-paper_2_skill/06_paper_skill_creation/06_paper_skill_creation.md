# Paper Skill 创建指南

## 概述

本文档是 Paper Skill 创建的总领文档，提供从规范化 Markdown 文档创建 Paper Skill 的整体流程和指南。通过本章节，您将了解 Paper Skill 的创建流程、目录结构、文档格式和最佳实践，为技能文档的创建和管理提供基础。

## Paper Skill 在知识体系中的定位

在[项目理念与工程化框架](../SKILL.md#项目理念与工程化框架)中，Paper Skill 是资料整理的**最终产物**，用于沉淀可复用的结构化技能知识；但支撑它的是整个 Wiki 知识库体系，而非孤立的文档堆：

1. **消费知识网络**：Paper Skill 从规范化材料（含 ground truth）中提取，内容必须有真实材料依据
2. **回馈知识网络**：Paper Skill 通过索引文件与相对路径链接回原始材料，形成可追溯的知识节点
3. **非 RAG 模式**：检索与验证沿显式交叉引用进行，不依赖向量相似度隐式检索
4. **入库即构建**：在资料入库阶段完成关联，Skill 提取只是知识网络建设的收尾环节

## 基础要求

Paper Skill 作为技能文档的一种类型，应遵循 [技能创建指南](../02_skill_creation/02_skill_creation.md) 中的基础要求，包括：

- **逻辑层级结构**：遵循从宏观到微观的结构设计原则，确保文档层次分明、逻辑连贯
- **文档长度规范**：根据内容需求控制文档长度，确保内容简洁明了、重点突出
- **技能创建指南**：遵循技能文档的基本结构和格式规范

## 创建流程

### 1. 分析文章内容

- **阅读文章**：仔细阅读文章的标题、摘要、引言和方法部分
- **识别核心技术**：确定文章中最具代表性的技术术语或创新点
- **提取关键信息**：收集实验设计、数据分析方法和应用方向等关键信息

### 2. 确定技能名称

- **核心技术术语**：选择文章中最独特、最能代表核心内容的术语
- **期刊信息**：提取期刊的完整名称，将空格替换为连字符
- **发表年份**：从文章元数据中获取准确的发表年份
- **语言要求**：
  - **重要强调**：对于英文文献，技能名称必须使用英文
  - 确保所有术语和期刊名称都使用英文表达
  - 避免使用中文或其他语言的词汇
- **组合命名**：按照 [核心技术术语]-[期刊全称]-[发表年份] 的格式组合

### 3. 创建目录结构

- **主题分类**：根据文章的研究主题，选择或创建相应的主题目录
- **技能目录**：创建以技能名称命名的目录（全小写字母）
- **SKILL.md**：在技能目录中创建 SKILL.md 文件

### 4. 编写技能文档

- **主文档结构**：按照 SKILL.md 格式组织内容，作为技能的主入口
- **分类文档结构**：为每篇论文创建10个分类文档，分别从不同角度分析论文内容
- **内容撰写**：基于文章内容，撰写各个部分的详细内容
- **重点突出**：重点关注技术的实现手段、数据分析方法和应用方向
- **格式规范**：确保文档格式规范、内容完整、逻辑清晰
- **溯源信息**：在主文档中添加溯源信息，指引用户通过索引文件找到原始规范化论文材料

### 5. 溯源信息规范

每篇paper skill的主文档（SKILL.md）应包含溯源信息部分，内容如下：

```markdown
## 溯源信息

本技能文档基于规范化处理后的论文材料创建。如需查看原始规范化论文材料的位置，请参考以下索引文件：

- **主题分类索引**：`paper_skills/by_topic/index.md`
- **方法分类索引**：`paper_skills/by_method/index.md`
- **期刊分类索引**：`paper_skills/by_journal/index.md`

在索引文件中，您可以通过技能名称 "[技能名称]" 找到对应的源文档路径，从而访问原始规范化论文材料。
```

这样可以确保用户能够方便地溯源到原始规范化论文材料，提高文档的可追溯性。

### 6. 引用规范

在编写paper skill的详细内容时，特别是在讨论和争论的关键点上，应添加引用，说明信息来源。引用应包括：

1. **引用标记**：在正文中使用上标引用标记，如 [^1]
2. **引用内容**：在文档末尾添加引用部分，包括：
   - **章节文件**：完整的章节文件路径，如 `llm_processed/Springer_Nature/Nature_Aging/s43587-022-00196-x/chapters/methods.md`
   - **章节**：具体的章节名称，如 "Raw LC–MS/MS data processing section"
   - **原文**：原始内容的英文原文

**引用示例**：

```markdown
[^1]: **章节文件**：`llm_processed/Springer_Nature/Nature_Aging/s43587-022-00196-x/chapters/methods.md`
       **章节**：Raw LC–MS/MS data processing section
       **原文**："Raw DDA data were searched with MaxQuant to generate a quantitative DDA dataset (.txt files) and to generate a DIA library."
```

**要求**：
- 所有引用必须包含完整的章节文件路径，确保能够直接定位到原始章节文件
- 引用的原文必须与原始章节文件中的内容完全一致
- 对于重要的技术细节、实验方法和结果，必须添加引用
- 确保引用的章节文件确实存在于项目中

这样可以确保所有重要信息都有明确的来源，提高文档的可信度和可验证性，同时方便用户直接定位到原始章节文件进行验证。

### 7. 分类标准

对于科研论文（包括期刊论文、会议论文、书籍等），应从以下10个角度进行拆分和分析：

1. **科学研究基础**：研究背景、科学问题、文献综述、研究设计等
2. **实验系统**：样本与材料、实验方法、技术细节、实验流程等
3. **数据分析方法**：数据处理流程、分析工具、统计方法、关键分析步骤等
4. **技术实现细节**：技术架构、核心模块、代码实现、技术特点等
5. **结果与发现**：主要结果、关键发现、结果验证、结果解释等
6. **技术创新与优势**：方法学创新、技术优势、与现有技术的比较、应用价值等
7. **应用与使用场景**：研究应用、临床应用、药物开发应用、其他潜在应用等
8. **局限性与挑战**：技术局限性、方法学挑战、应用限制、生物学挑战等
9. **未来发展与展望**：技术发展趋势、方法学创新、应用扩展、技术影响等
10. **学术规范与交流**：研究伦理、数据管理、论文发表、学术交流、知识产权保护等

### 8. Source目录

- **用途**：存放与论文相关的公开代码、脚本以及使用的R包或Python包的源代码
- **位置**：位于技能目录下，与SKILL.md文件同级
- **内容**：包括但不限于：
  - 论文中使用的分析脚本
  - 相关软件工具
  - 数据集
  - 其他相关资源

### 9. 目录结构

每篇论文的skill目录结构如下：
- `SKILL.md`：主技能文档，提供整体概述和入口
- `01_scientific_research_foundation.md`：科学研究基础
- `02_experimental_system.md`：实验系统
- `03_data_analysis_methods.md`：数据分析方法
- `04_technical_implementation.md`：技术实现细节
- `05_results_and_findings.md`：结果与发现
- `06_technical_innovation.md`：技术创新与优势
- `07_applications_and_use_cases.md`：应用与使用场景
- `08_limitations_and_challenges.md`：局限性与挑战
- `09_future_development.md`：未来发展与展望
- `10_academic_standards.md`：学术规范与交流
- `source/`：存放相关代码和脚本

### 10. 更新索引文件

- **分类索引**：更新相应分类目录（by_topic、by_method、by_journal）下的 index.md 文件
- **技能信息**：添加新创建的技能文档信息，包括技能名称、源文档、来源路径和对应 LLM 文档路径
- **文档数量**：更新技能文档数量统计
- **交叉引用**：确保在不同分类目录中创建的技能文档都能在相应的索引文件中找到

## 最佳实践

1. **准确性**：确保技能文档内容准确反映原始文章的核心内容
2. **完整性**：包含技能的各个方面，从技术原理到应用指南
3. **一致性**：保持命名规范和目录结构的一致性
4. **可读性**：使用清晰的结构和格式，提高文档的可读性
5. **可追溯性**：确保技能文档能够追溯到原始源文档
6. **同步更新**：每次新建或修改技能文档时，同步更新相应分类目录下的索引文件
7. **交叉引用**：在不同分类目录中创建的技能文档应在所有相关索引文件中更新
8. **路径一致性**：确保索引文件中的路径正确指向技能文档和对应 LLM 文档

## 常见问题

### Q: 如何选择核心技术术语？
A: 选择文章中最具代表性、最独特的技术术语或缩写，优先考虑文章标题、摘要或引言中反复强调的技术创新。

### Q: 如何处理多个核心技术术语的情况？
A: 选择最具代表性的一个技术术语，或使用最能概括文章核心内容的术语组合。

### Q: 如何确定主题分类？
A: 根据文章的研究主题，选择最相关的主题分类，或创建新的主题分类。

### Q: 技能文档的长度有什么要求？
A: 技能文档应遵循 [文档长度规范](../02_skill_creation/02_03_document_length.md) 中的要求，根据内容需求控制文档长度，确保内容详细全面但不过于冗长，重点突出核心内容和关键信息。
