# 终端操作指南

## 概述

本文档作为 Paper2Skill 工具终端操作的指南，专门为 Trae 在 PowerShell 环境下运行命令时提供参考。通过本章节，您将了解终端操作的注意事项、常见错误及解决方案，确保命令执行的准确性和效率。

## 快速参考指南

为了方便用户快速查阅和执行常用命令，我们在项目根目录下创建了 `guide` 目录，用于存放各种操作指南和脚本运行说明。

### guide 目录用途

- **存放特定任务的操作指南**：针对具体任务的详细操作步骤和命令示例
- **脚本运行说明**：提供脚本的使用方法和参数说明
- **快速参考资料**：便于用户直接查阅，无需通过指令请求

### 现有指南文件

- **pdf_processing_guide.md**：PDF 处理脚本的运行指南

### 使用方法

1. 直接打开 `guide` 目录中的对应指南文件
2. 按照指南中的步骤和命令执行操作
3. 如需添加新的指南文件，请遵循现有命名规范

## 适用范围

本指南适用于以下场景：
- Trae 在 PowerShell 环境下执行命令
- 需要创建目录结构、运行脚本等操作
- 遇到命令执行错误需要排查时

## 注意事项

- 本指南主要针对 PowerShell 环境，其他 shell 环境可能有不同的命令语法
- 命令执行时请确保使用正确的路径分隔符（Windows 系统使用反斜杠 `\`）
- 执行命令前请确认当前工作目录是否正确
- 对于复杂命令，建议先在测试环境中验证
