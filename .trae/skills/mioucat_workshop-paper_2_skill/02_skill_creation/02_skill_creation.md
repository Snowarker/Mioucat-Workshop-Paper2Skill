## 技能结构标准

### 基本结构

一个标准的技能文档应包含以下部分：

1. **文档头**：包含文档标题、创建日期、版本信息
2. **技能概览**：提取的技能总数和分类统计
3. **核心技能**：按重要性排序的核心技能列表
4. **详细技能**：包含详细描述的技能列表
5. **技能关系**：技能之间的层次和关联关系
6. **应用场景**：技能的具体应用场景
7. **参考资料**：技能来源和相关资源

### 扩展结构

根据需要，您可以添加以下扩展部分：

- **学习路径**：技能的推荐学习顺序
- **技能评估**：技能水平的评估标准
- **相关技能**：与本文档相关的其他技能
- **常见问题**：关于技能的常见问题和解答

## 技能文档格式规范

### 标题层级

使用 Markdown 标题层级表示文档结构：

```markdown
# 主标题（文档标题）

## 二级标题（主要部分）

### 三级标题（子部分）

#### 四级标题（详细子部分）
```

### 内容格式

- **列表**：使用有序列表和无序列表组织内容
- **表格**：使用表格展示结构化数据
- **代码块**：使用代码块展示命令和代码示例
- **引用**：使用引用格式强调重要内容

## 技能文档创建流程

### 标准创建流程

1. **准备阶段**：确定文档目标和范围
2. **收集阶段**：收集技能信息
3. **组织阶段**：组织技能信息，建立结构
4. **编写阶段**：编写文档内容
5. **审核阶段**：审核文档质量
6. **发布阶段**：发布文档
7. **维护阶段**：维护和更新文档

### 质量控制

- **内容质量**：确保技能描述准确无误，包含所有必要信息
- **文档风格**：使用一致的文档风格和格式
- **组织管理**：使用统一的文件命名规范，按照分类存储文档
- **审核流程**：进行自我审核、同行评审和用户反馈收集

## 最佳实践

1. **预设计结构**：在编写文档前预先设计结构，确保逻辑清晰
2. **保持一致性**：在整个文档中保持结构一致性，包括标题格式、内容组织和分类标准
3. **灵活调整**：根据实际需要灵活调整结构，适应不同类型的技能文档
4. **定期审查**：定期审查和优化文档结构，确保文档质量

## 常见问题及解决方案

### 结构问题

| 问题类型 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 层级过深 | 内容分类过细 | 合并相似层级，简化内容结构 |
| 层级过浅 | 内容组织混乱 | 细化内容分类，增加中间层级 |
| 逻辑混乱 | 内容顺序不当 | 重新梳理逻辑关系，调整内容顺序 |
| 重点不突出 | 内容组织不合理 | 调整内容位置，使用视觉强调 |

### 内容问题

| 问题类型 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 技能遗漏 | 信息收集不完整 | 重新收集技能信息，确保无遗漏 |
| 分类错误 | 分类标准不明确 | 建立明确的分类标准，重新分类技能 |
| 描述模糊 | 描述语言不精确 | 使用具体、明确的语言描述技能 |
| 信息过时 | 技能信息未更新 | 定期更新技能信息，确保时效性 |
