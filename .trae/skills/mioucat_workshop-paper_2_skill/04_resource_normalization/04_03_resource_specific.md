# 特定资源处理与最佳实践

## 资源特定处理

### 1. PDF 文档

#### 1.1 学术期刊

- **结构特点**：包含摘要、引言、方法、结果、讨论等标准部分
- **图片处理**：通常包含多个图表，需要按顺序编号
- **参考文献**：使用特定格式（数字编号或作者-年份）

**详细处理规则**：请参考 [PDF 文档处理规则索引](../../../../llm_standard/std_guide/pdf_guide/index.md)，其中包含了各种期刊的具体处理规则，包括：
- Elsevier 期刊（如 Cell、Cancer Cell、Molecular & Cellular Proteomics）
- Springer Nature 期刊（如 Nature 系列）
- Wiley 期刊（如 Angewandte Chemie）
- ACS 期刊（如 JACS）

#### 1.2 会议论文

- **结构特点**：通常比期刊论文简短，包含摘要、方法、结果等核心部分
- **图片处理**：图表数量较少，需要保持清晰度
- **参考文献**：格式多样，需要统一处理

#### 1.3 预印本

- **结构特点**：格式较为灵活，可能缺少正式期刊的部分结构
- **图片处理**：可能包含原始实验数据图，需要保持完整性
- **参考文献**：可能使用预印本引用格式

#### 1.4 专利文献

- **结构特点**：包含摘要、权利要求、说明书等特定部分
- **图片处理**：技术图纸和流程图较多，需要保持清晰
- **参考文献**：专利引用格式特殊

#### 1.5 技术报告

- **结构特点**：包含执行摘要、方法、结果、建议等部分
- **图片处理**：可能包含大量数据图表和技术示意图
- **参考文献**：通常包含技术文献和标准

#### 1.6 书籍章节

- **结构特点**：包含章节介绍、主体内容、总结等部分
- **图片处理**：可能包含插图和表格
- **参考文献**：书籍引用格式特殊

### 2. HTML 文档

#### 2.1 学术网站

- **结构特点**：包含标题、作者、发布日期、正文等部分
- **图片处理**：可能包含嵌入式图片和图表
- **链接处理**：需要保留重要的外部链接

#### 2.2 科技博客

- **结构特点**：通常包含标题、作者、发布日期、正文、评论等部分
- **图片处理**：可能包含截图和示意图
- **格式处理**：可能使用特殊的博客格式

#### 2.3 在线教程

- **结构特点**：包含标题、步骤说明、代码示例等部分
- **图片处理**：可能包含截图和操作示意图
- **代码处理**：需要保留代码格式和语法高亮

#### 2.4 新闻文章

- **结构特点**：包含标题、作者、发布日期、正文、来源等部分
- **图片处理**：可能包含新闻图片和图表
- **引用处理**：需要保留新闻来源引用

### 3. GitHub 项目

#### 3.1 开源软件

- **结构特点**：包含 README、代码文件、文档等部分
- **文档处理**：主要关注 README 和技术文档
- **代码处理**：可能需要提取关键代码片段

#### 3.2 数据集

- **结构特点**：包含数据集描述、使用说明、数据文件等部分
- **文档处理**：关注数据集描述和使用说明
- **数据处理**：可能需要提取数据结构和示例

#### 3.3 技术文档

- **结构特点**：包含安装说明、使用指南、API 文档等部分
- **文档处理**：关注技术文档的结构和内容
- **格式处理**：可能使用 Markdown 或其他文档格式

## 拓展性设计

### 1. 可扩展的资源处理框架

#### 1.1 模块化设计

- **核心模块**：通用的文档处理流程
- **资源模块**：针对特定类型资源的处理规则
- **来源模块**：针对特定来源的处理规则

#### 1.2 资源处理规则文档

使用 MD 文档定义资源特定的处理规则，每个资源类型创建一个独立的 MD 文档：

**示例：Cell 期刊处理规则文档**

```markdown
# Cell 期刊处理规则

## 基本信息
- **出版社**：Elsevier
- **期刊**：Cell

## 结构要求

### 必需部分
- In Brief
- Highlights
- Abstract
- Introduction
- Results
- Discussion
- Methods
- References

### 可选部分
- Author Contributions
- Conflict of Interest

## 图片命名规则
- **主图表**：figure_1.jpeg, figure_2.jpeg, ...
- **补充图表**：figure_s1a.jpeg, figure_s1b.jpeg, figure_s2.jpeg, ...

## 特殊处理
- 补充图表通常包含多个小图，需要单独处理
- 参考文献使用数字编号格式
```

### 2. 新增资源处理流程

当需要添加新资源类型的处理规则时，遵循以下步骤：

1. **分析资源结构**：了解资源的特有结构和格式要求
2. **创建处理规则文档**：为资源类型创建一个 MD 文档，定义处理规则
3. **测试处理**：使用测试资源验证处理效果
4. **优化规则**：根据测试结果优化处理规则
5. **文档更新**：更新本指南，添加新资源类型的处理方法

### 3. 来源扩展

当需要添加新来源的处理规则时，遵循以下步骤：

1. **识别来源**：确认来源的准确名称
2. **创建目录**：在 `llm_processed` 下创建来源目录
3. **添加资源**：在来源目录下添加资源子目录
4. **配置规则**：为来源和资源添加处理规则文档
5. **测试验证**：使用该来源的资源测试处理效果

## 最佳实践

### 1. 预处理检查

- **文件完整性**：确保所有必要的文件都已提取
- **结构检查**：检查文档结构是否完整
- **图片检查**：检查图片是否完整且清晰

### 2. 处理流程

1. **分类归档**：将资源分类到正确的类型和来源目录
2. **结构整理**：整理文档结构，确保所有部分完整
3. **章节分离**：直接分析原始文档，将内容分离为多个章节
4. **章节存储**：将分离的章节存放在chapters目录中
5. **图片处理**：将图片文件移动到images目录中并按照规则重命名
6. **引用更新**：更新文档中的图片引用
7. **质量检查**：检查处理结果的质量

### 3. 质量控制

- **一致性**：确保同一类型资源的处理结果一致
- **准确性**：确保内容和引用的准确性
- **完整性**：确保所有内容都被正确处理
- **可读性**：确保处理后的文档易于阅读和理解

## 常见问题与解决方案

### 1. 来源分类错误

- **问题**：将资源错误分类到错误的来源目录
- **解决方案**：参考官方资源信息，确保来源分类准确

### 2. 内容缺失

- **问题**：方法部分、参考文献或补充信息缺失
- **解决方案**：从原始资源中提取完整内容，确保所有章节都被包含

### 3. 图片标注错误

- **问题**：图片引用与实际内容不匹配
- **解决方案**：仔细核对每个图片的内容，确保引用正确

### 4. 图片文件管理

- **问题**：图片文件过多或命名混乱
- **解决方案**：删除多余图片，按照统一规则重命名

### 5. 格式不一致

- **问题**：文档格式与资源类型要求不一致
- **解决方案**：参考资源类型的格式要求，统一文档格式

## 故障排除

### 1. 常见错误

| 错误类型 | 原因 | 解决方案 |
|---------|------|----------|
| 目录结构错误 | 资源类型或来源分类错误 | 参考官方信息，修正分类 |
| 图片丢失 | 图片提取失败 | 从原始资源重新提取图片 |
| 引用错误 | 图片路径或文件名错误 | 检查并修正引用路径 |
| 内容缺失 | 资源提取不完整 | 重新处理资源，确保完整提取 |
| 格式不一致 | 处理规则不统一 | 统一处理规则，确保格式一致 |

### 2. 错误处理策略

- **记录错误**：记录处理过程中的错误和异常
- **分析原因**：分析错误产生的原因
- **制定方案**：制定针对性的解决方案
- **实施修复**：实施修复措施
- **验证效果**：验证修复效果
