# 资源规范化处理

## 概述

本文档作为 Paper2Skill 工具资源规范化处理的总领文档，介绍如何对不同类型的资源进行规范化处理。通过本章节，您将了解各种资源的标准化处理流程、核心结构、文档要求以及特定类型资源的处理规则，为后续的技能提取和文档管理提供基础。

## 资源类型分类

### 1. PDF 文档

- **学术期刊**：经过同行评审的学术论文
- **会议论文**：学术会议发表的论文
- **预印本**：未经过同行评审的预发布论文
- **专利文献**：专利申请和授权文件
- **技术报告**：研究机构发布的技术报告
- **书籍章节**：学术书籍中的章节

### 2. HTML 文档

- **学术网站**：大学、研究机构的学术网页
- **科技博客**：技术领域的专业博客
- **在线教程**：技术和学术在线教程
- **新闻文章**：科技新闻和报道

### 3. GitHub 项目

- **开源软件**：开源代码库
- **数据集**：公开数据集
- **技术文档**：项目技术文档

## 处理流程

### 标准处理流程

1. **文档分析**：分析原始 PDF 文档的结构和内容
2. **类型识别**：识别 PDF 文档类型（期刊、会议论文、预印本等）
3. **来源识别**：识别出版社和期刊信息
4. **唯一标识符确认**：从原始 MD 文档中查找并确认文章的唯一标识符，优先使用 DOI 后缀
5. **目录创建**：在 `llm_processed/` 目录下按照三级目录结构创建相应的子目录
6. **章节拆分**：将内容分离为多个章节文件
7. **图片处理**：处理图片文件，按照规则重命名和引用
8. **入口文档创建**：创建标准化的入口文档
9. **质量检查**：检查处理结果的质量和完整性

### 章节提取原则

**核心原则**：能够拆就一定要拆，只要原始文档中存在的章节，都应该被提取和拆分。

**必需章节**：
- 定义：一般来说论文的 MD 文档必定会含有的部分，几乎所有科研论文都会包含的章节
- 处理逻辑：只要出现就必须提取；如果在原始文档中未发现，必须提醒用户进行检查确认
- 示例：Authors、Correspondence、Abstract、Introduction、Results、Discussion、Methods、Acknowledgments、Author Contributions、Competing Interests、References

**可选章节**：
- 定义：这些章节可能在某些论文中存在，但不是所有论文都包含的章节
- 处理逻辑：只要在原始 MD 文档中明确出现，就必须提取；只有在原始文档中确实不存在时才可以不提取
- 示例：Additional Information、Extended Data Figure、Supplementary Information、Data Availability、Abbreviations 等

**章节顺序原则**：
- 入口文档中的章节顺序必须与原始 MD 文档中的章节出现顺序完全一致
- 章节导航、文档结构列表和章节文件链接都应遵循原始文档的顺序
- 任何章节顺序的调整都应基于原始文档的实际结构，不得随意重新排序
- 入口文档的所有部分（文档结构、章节导航、章节文件链接）都必须保持章节顺序的一致性
- 新增章节时，必须按照原始文档中的出现顺序插入到正确位置

**章节完整性原则**：
- 所有拆分出来的章节文件必须在入口文档中有所体现
- 入口文档应包含所有章节的导航链接和简要描述
- 章节文件与入口文档的内容应保持一致，确保无遗漏

**重要说明**：
- 必需章节的定义基于论文的一般结构，而非内容重要性
- 所有章节的提取都应保持内容的完整性和结构的准确性
- 对于必需章节，如果在原始文档中未找到精确匹配的标题，应检查是否存在类似表述或结构

## 使用方法

1. **识别文档类型**：确定 PDF 文档的类型（期刊、会议论文等）
2. **查找处理规则**：在 PDF 文档处理规则索引中找到对应的处理规则文档
3. **遵循处理流程**：按照规则文档中的指导进行处理
4. **确认唯一标识符**：从原始 MD 文档中查找并确认文章的唯一标识符，优先使用 DOI 后缀
5. **创建目录结构**：在 `llm_processed/` 目录下按照三级目录结构创建相应的子目录
6. **执行章节拆分**：将内容分离为多个章节文件
7. **处理图片**：按照规则处理和命名图片
8. **创建入口文档**：使用标准化模板创建入口文档
9. **进行质量检查**：确保处理结果符合要求

## 常见问题及解决方案

| 问题类型 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 章节识别错误 | 标题格式不一致 | 检查标题格式，确保正确识别 |
| 图片丢失 | 图片提取失败或命名错误 | 重新提取图片，按照规则重命名 |
| 结构不完整 | 章节边界识别不准确 | 调整章节识别规则，确保完整提取 |
| 格式问题 | 特殊格式处理不当 | 优化格式处理规则，确保正确显示 |
| 引用错误 | 图片路径或文件名错误 | 检查并修正引用路径 |
| 目录结构错误 | 出版社或期刊分类错误 | 参考官方信息，修正分类 |

## 总结

资源规范化处理是 Paper2Skill 工具处理流程的重要环节，通过规范化处理，您可以确保不同类型资源的结构、格式和内容得到一致、准确的处理。本章节提供了全面的处理方法和指南，帮助您高效、准确地处理不同类型的资源。

随着资源格式的不断变化，资源规范化处理方法也需要持续更新和优化。通过不断改进处理规则和流程，您可以提高处理效率和质量，为 Paper2Skill 工具的使用提供更好的支持。
