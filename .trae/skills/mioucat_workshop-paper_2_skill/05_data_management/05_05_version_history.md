# 版本更新记录

## 概述

本文档是项目的版本更新记录（changelog），记录每个版本的提交内容与功能变更。**README 只展示最近两个版本的变更摘要，完整的历史版本记录以本文档为权威来源**。每个版本发布时，需将变更内容追加到本文档中。

## 当前版本：0.3.0

**发布日期**：2026-09-11

### 0.3.0 变更内容

- **新增 `manage_models.py` 独立模型管理脚本**：将模型检查与下载从 `process_pdf.py` 中拆分为独立脚本，支持四种用法（默认检查并自动补齐、`--check` 版本报告、`--update` 强制更新、`--prune` 清理旧目录），`process_pdf.py` 启动时自动调用
- **GPU 加速配置**：接入 llama.cpp + CUDA 运行时（cudart64_12.dll 等），修复 CUDA DLL 缺失导致静默退回 CPU 的问题，实测推理速度提升约 20 倍（5.5 t/s → 108 t/s）
- **模型统一目录管理**：所有模型（版面、文本、GGUF）统一存放于 `models/` 目录，通过环境变量（`MODEL_CACHE_DIR`、`SURYA_GGUF_LOCAL_MODEL_PATH`、`HF_HOME`）配置，避免占用 C 盘
- **Skill 文档结构化重构**：技能文档由扁平结构重构为 7 大分类文件夹组织，项目理念（Wiki 知识库体系）并入入口文档 SKILL.md 总纲
- **新增代码包来源识别**：支持 R 包（CRAN/Bioconductor）与 Python 包（PyPI/conda-forge）的文档识别、获取方案与版本管理
- **确立 Wiki 知识库工程化理念**：以真实材料交叉引用构建知识网络（非 RAG 向量检索），入库即构建知识网络，保留每份资料的 ground truth

## 维护规范

1. **版本号递增**：遵循语义化版本（主版本.次版本.修订号），提交前与 README 中版本号保持一致
2. **新增版本时**：将"历史版本"中的 0.2.0 条目保留在本文档，README 中只更新为最近两个版本（当前版本 + 上一版本）
3. **变更描述**：每个条目描述功能新增、修改或修复，标注关联脚本或文档
4. **发布流程**：版本发布时同步更新 README（版本号、最近两个版本变更摘要）与本文档（完整变更记录）
