# 文档规整化标准

## 概述

本指南作为 Paper2Skill 工具中 LLM 处理阶段的文档规整化入口文档，提供文档规整化的基本流程和参考链接。详细的资源规范化处理规则和标准，请参考资源规范化处理模块的相关文档。

## 规整化流程

文档规整化是 LLM 处理前的重要步骤，主要包括以下流程：

1. **文档分析**：分析原始文档的结构和语言
2. **标题处理**：保持与原始文档一致的语言和格式
3. **图片处理**：识别、筛选、重命名和存储图片
   - **详细规范**：请参考 [入口文档与图片处理规范](../04_resource_normalization/04_02_document_requirements.md)
4. **表格处理**：将表格作为独立章节文档提取并保持完整结构
5. **章节拆分**：将文档拆分为多个章节文件
6. **入口文档生成**：生成包含导航和图片的入口文档
   - **详细规范**：请参考 [入口文档与图片处理规范](../04_resource_normalization/04_02_document_requirements.md)
7. **目录创建**：创建标准目录结构
8. **内容验证**：验证规整化后的文档内容完整性

## 关键原则

1. **语言一致性**：始终保持与原始文档相同的语言，不进行翻译
2. **图片规范**：按照标准规则命名和引用图片
3. **表格规范**：将表格作为独立章节文档提取，保持完整结构并在原章节中引用
4. **结构清晰**：使用标准目录结构和文档格式
5. **内容完整**：保留原始文档的所有内容和格式
6. **引用正确**：使用相对路径引用图片、表格和章节文件，符合 Obsidian 格式要求

## 适用范围

本指南适用于所有类型文档的规整化处理，包括：
- PDF 文档（期刊论文、会议论文、预印本等）
- HTML 文档（学术网站、科技博客等）
- GitHub 项目文档
